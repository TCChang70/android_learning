## 二、各題庫「側重主題」分析

主題以 Oracle 1Z0-830 官方考綱 domain 對照，並加註每個題庫明顯偏重的部分。

### 1. `1Z0-830_Question_Bank.md`（javainuse，221 題）— 最完整但零散
- **測驗結構**：Test 1（題 1–66）、Test 2（67–132）、Test 3（部分題目重複）、Test 4、Test 5。
- **側重**：時間/日期（DateTimeFormatter pattern）、Stream/Collectors、record 合法性、sealed class、`var` 宣告、`module-info` 語法、ConcurrentHashMap 參數計算、text block、Optional、switch 語法。
- **特色**：題型長、選項多、有 Choose two/three/all apply；適合「掃大量題目」階段，但各題主題未標章節，需靠題目內容自行判斷。

### 2. `1Z0-830_Src_Questions.md`（源碼題）— 最接近實戰「讀 code 答題」
- **側重**：Concurrency（volatile/AtomicInteger、WorkStealingPool、virtual threads）、Stream 細節（reduce identity、takeWhile/dropWhile、parallel distinct）、String/text block、Enum、Array 比較（compare/mismatch）、JPMS（module 可見性、jdeps、JImage）、Path/IO（resolve/relativize、BufferedWriter）、Serialization、LocalDateTime DST、switch pattern matching、SequencedCollection。
- **特色**：幾乎都是「給一段源碼問輸出」，對應官方真題「Source code review」風格；Part 1 就有 27 大題。

### 3. `1Z0-830_Online_Practice.md`（70 題）
- **S1 = Mastery Exam Prep（50 題）**：官方 domain 均衡分布，情境題多（先敘述情境再給程式碼），含詳細講解；主題涵蓋 Streams/Lambda、OOP、Collections、Date/Time、Exceptions、Concurrency、Packaging、Logging。
- **S2 = Cert Empire（20 題）**：免費預覽題，偏基礎 syntax（while、try-with-resources、LinkedList、interface 語法），難度較低。
- **特色**：S1 的「情境式長描述」與官方真題最像，是很好的仿真練習。

### 4. `1Z0-830_Online_Practice_2.md`（46 題 + 導讀）
- **Part A = MyExamCloud（22 題）**：主題較雜，偏 Stream/Lambda、Modules、ReentrantLock、I/O、program flow、text block、record、sealed、virtual threads、localization。
- **Part B = Javarevisited（10 題）**：Medium 精選，主題：reduce、labeled loop、var 宣告、ArrayDeque、switch pattern、DateTimeFormatter `CM`、平行 stream、synchronizedList+invokeAll、record+IntStream。
- **Part C = DBExam（10 題）**：偏 Path/Files、runtime image、interface、parallel stream、TWR var、catch 提升、while、module、sealed、service provider。
- **Part D = TechExamLexicon（4 題）**：pattern variable scope、Stream 用法、record compact constructor、generic invariance。
- **Part E**：Anasss 抽認卡導讀（指向 Study_Guide）。

### 5. `1Z0-830_Web_Questions_1.md`（19 題）— 網路精選
- **A = freecram（9 題）**：TreeMap.subMap、do-while、wildcard、Text Block、synchronized、DoubleSummaryStatistics、switch pattern、final class、method overloading。
- **B = TheExamsLab（6 題）**：getCompactNumberInstance、Files.move、module system、StringBuilder、ExecutorService、Optional。
- **C = TechExamLexicon（4 題）**：pattern variable scope、Stream 使用、record compact constructor、generic invariance。
- **特色**：短小明確，適合快速熱身。

### 6. `1Z0-830_Web_Questions_2.md`（25 題）— 網路精選進階
- **A = Medium/Javarevisited（10 題）**：與 Online_Practice_2 Part B 同源，主題見上。
